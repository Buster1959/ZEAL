# ZEAL Documentation Screenshots

Actual ZEAL desktop and mobile screenshots will be added here after capture from
a generic test installation. Do not reuse Visual Climate Scheduler screenshots:
the integrations are independent and their screens describe different control
boundaries.

## Required captures

- Desktop Overview and Setup hierarchy
- Desktop Schedule editor
- Desktop Quick Change and Away mode
- Desktop Downloads section
- Mobile Overview/Setup
- Mobile Schedule exact-entry view
- Mobile Quick Change
- Mobile Away status and **End Away now**

## Privacy review before commit

- Use generic zone, room and entity names.
- Remove addresses, person names, location names, URLs, IP addresses and device
  identifiers tied to a real installation.
- Check browser tabs, notifications and status bars.
- Do not show access tokens, credentials, calendar event titles or downloaded
  configuration/audit contents from a real home.
- Crop unused surrounding screen content.
- Give each image a descriptive lowercase filename.
